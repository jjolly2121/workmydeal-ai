# WorkMyDeal AI Frontend

This folder contains the React/Vite frontend for WorkMyDeal AI.

## Setup

```bash
npm install
```

## Run

```bash
npm run dev -- --host 127.0.0.1 --port 5173
```

Open:

```text
http://127.0.0.1:5173/
```

The Spring Boot backend must also be running on `http://localhost:8080`.

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
